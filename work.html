Instructional design and learning systems

LMS implementation and scalable onboarding

The challenge

Maple had online courses available for new hires, but they were scattered across the existing learning platform and lacked a defined learning path. There was no cohesive onboarding program connecting self-paced learning with live training, hands-on practice, or knowledge checks.

My role

I designed and built a structured onboarding program in Coassemble, establishing a framework for how the platform would be used to support learning at Maple.

I organized content into a defined learning path with time-bound completion expectations. I integrated self-paced courses with live, hands-on activities and knowledge checks tied directly to the material learners had completed. The program incorporates a range of learning formats, including modules, videos, quizzes, and interactive activities.

I also built learner feedback into the program so each cohort could help inform future improvements. The program has since expanded beyond onboarding to support professional development and training on new processes.

Impact

  • 100+ new hires have completed the onboarding program
  • 4.5/5 average satisfaction rating from new hires
  • Created a consistent, structured onboarding experience where none previously existed
  • Established a scalable learning infrastructure supporting onboarding and professional development
  • Created an ongoing feedback and iteration cycle to improve the learner experience
